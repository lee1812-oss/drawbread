1보낼 자료 고르기

참고자료 기준일은 단가표 날짜이고, 위 업데이트 시각은 이 화면을 고친 시각입니다.

2받는 분 정보

받는 분 휴대폰 번호 문자일 때 필요

상호 또는 성함 선택

3보낼 글 확인

자동으로 채워집니다. 필요하면 고쳐서 보내세요.

4보내기

휴대폰 문자 앱이 열리고 번호·글이 채워집니다. 문자 앱에서 「보내기」만 누르세요.

공유 창에서 「카카오톡」 → 받을 친구나 방을 고르세요. 카톡은 친구로 저장된 분께만 보낼 수 있습니다.

링크 대신 파일 자체를 보냅니다. 공유 창에서 「카카오톡」을 고르세요. 회사소개서는 크기가 커서 받는 데 시간이 걸릴 수 있습니다.

PC에서는 문자 보내기가 안 됩니다. 복사한 뒤 카카오톡 PC 대화창에 붙여 넣으세요.

쓰는 순서

  1. 슬랙 #영업-자료 → 「회사소개서&단가표」 탭 → 「회사소개서·단가표 보내기」를 누릅니다.
  2. 보낼 자료를 고르고 받는 분 휴대폰 번호를 넣습니다.
  3. 「문자로 보내기」 또는 「카카오톡으로 링크 보내기」를 누릅니다.
  4. 열린 문자·카톡 화면에서 받는 분을 확인하고 「보내기」를 누릅니다.

주의거래처별 할인 단가나 매입 단가는 이 화면에 없습니다. 필요하면 이사님께 확인해 주세요.

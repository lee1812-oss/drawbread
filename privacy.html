「빵을그리다 앱 모음」 개인정보처리방침

시행일: 2026년 10월 16일 · 운영: 빵을그리다(주)

「빵을그리다 앱 모음」(이하 "앱")은 빵을그리다(주) 직원이 배송 코스, 출고 확인, 거래처 길안내 업무에 사용하는 사내용 앱입니다. 앱은 아래와 같이 정보를 처리합니다.

1. 처리하는 정보

  • 거래처 업무 정보: 거래처 상호, 사업장 주소, 배송 품목·수량, 거래처 담당자 이름과 연락처(직원이 입력한 경우)
  • 배송 기록: 적재·배송 완료 시각, 특이사항 메모, 배송 완료 사진(직원이 올린 경우), 기록한 기기 이름
  • 위치 정보: 직원이 「출발」 또는 「지금 내 위치」 버튼을 누를 때만 도착 예정 시간을 계산하기 위해 사용하며, 위치 기록을 저장하거나 추적하지 않습니다.

2. 이용 목적

배송 코스 작성, 출고·배송 확인, 거래처 도착 예정 안내, 이카운트 판매자료 확인 등 사내 업무에만 이용합니다. 광고나 제3자 마케팅에 이용하지 않습니다.

3. 보관 장소와 기간

  • 업무 자료는 빵을그리다(주)의 구글 계정(구글 시트·구글 드라이브)과 직원 기기 안에 저장됩니다.
  • 배송 기록과 사진은 업무상 필요한 기간(최대 1년) 보관 후 삭제합니다.
  • 거래처 자료 파일은 암호화되어 있으며 직원용 암호가 있어야 열 수 있습니다.

4. 외부 서비스 이용

  • 티맵(SK open API): 길찾기·도착 시간 계산 (출발지·도착지 좌표 전송)
  • 구글(구글 시트·드라이브·Apps Script): 공유 저장
  • GitHub Pages: 앱 화면 제공

5. 제3자 제공

법령에 따른 경우를 제외하고 정보를 제3자에게 제공하지 않습니다. 도착 예정 문자는 직원 휴대폰의 문자 앱으로 해당 거래처 담당자에게만 보내집니다.

6. 정보 삭제 요청

거래처 담당자 또는 직원은 자신의 정보 열람·수정·삭제를 요청할 수 있습니다. 기기 안의 자료는 앱 설정의 「초기화」로 언제든 지울 수 있습니다.
